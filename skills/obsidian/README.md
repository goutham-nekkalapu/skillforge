# Obsidian Skills

Skills for integrating with [Obsidian](https://obsidian.md) vaults — saving notes, syncing content, and managing knowledge bases.

## Skills in This Group

| Skill | Platform | Description |
|-------|----------|-------------|
| [obsidian-save-cloud](obsidian-save-cloud/) | claude.ai | Save conversation content to an Obsidian vault on Google Drive |
| [obsidian-save-local](obsidian-save-local/) | Claude Code, Cursor | Save content to a local Obsidian vault via the Obsidian CLI |

## Install All Obsidian Skills

```bash
npx skillforge install obsidian

# Or via install script
./install.sh obsidian
```
