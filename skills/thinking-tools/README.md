# Thinking Tools

Structured reasoning, analysis, and communication skills for deeper thinking, better decisions, and clearer understanding.

## Skills in This Group

| Skill | Description |
|-------|-------------|
| [reasoning-playbook](reasoning-playbook/) | A playbook of 8 structured reasoning frameworks (first principles, pre-mortems, trade-offs, etc.) |
| [analogy-engine](analogy-engine/) | Generates precise, non-cliche analogies that make complex concepts click |
| [assumption-hunter](assumption-hunter/) | Surfaces hidden assumptions in arguments, plans, and proposals |
| [decision-autopsist](decision-autopsist/) | Reconstructs why a decision played out the way it did |
| [hype-deflator](hype-deflator/) | Separates signal from noise in technology trends, pitches, and media narratives |
| [mental-model-mapper](mental-model-mapper/) | Maps mental models to any domain or problem, Munger-style |
| [steelman-builder](steelman-builder/) | Constructs the strongest possible version of opposing arguments |
| [subtext-reader](subtext-reader/) | Surfaces what's not being said in emails, messages, and conversations |

All skills work on **claude.ai**, **Claude Code**, and **Cursor**.

## Install All Thinking Tools

```bash
npx skillforge install thinking-tools

# Or via install script
./install.sh thinking-tools
```
