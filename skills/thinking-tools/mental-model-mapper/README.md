# mental-model-mapper

Maps which mental models apply to any domain, problem, or situation and shows how each one illuminates the specifics—with concrete examples tied to the user's context, relevance ratings, limitations, and a recommended "lens stack" of 2–3 models to prioritize. It draws from physics, biology, economics, psychology, systems thinking, math, strategy, and engineering without forcing weak fits.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

## Trigger Phrases

```
"What mental models apply here?"
"How should I think about this?"
"What frameworks are useful for this?"
"Give me a Munger-style analysis"
"What lenses should I use?"
"Help me think through this"
"What mental models fit?"
"How would Munger think about this?"
```
