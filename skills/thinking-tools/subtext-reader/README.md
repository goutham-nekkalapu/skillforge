# subtext-reader

Surfaces what is not being said in any communication—emails, messages, meeting transcripts, Slack threads, or conversations. It identifies unstated concerns, political dynamics, emotional undertones, and hidden agendas so you can understand what is really going on beneath the surface.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

## Trigger Phrases

```
"What are they really saying?"
"Read between the lines"
"What's the subtext here?"
"What's not being said?"
"What are they actually thinking?"
"Decode this email"
"What's the real message?"
"What's really going on?"
```
