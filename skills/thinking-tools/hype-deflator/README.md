# hype-deflator

Separates signal from noise in trending technologies, startup pitches, media narratives, and industry hype cycles. The agent applies a first-principles filter to claims—testing physics, economics, adoption, and history—flags common hype patterns, and returns a calibrated verdict (including when the narrative understates the opportunity). The goal is forensic calibration, not reflexive cynicism.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

