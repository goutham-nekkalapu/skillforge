# prompt-archeologist

Reverse-engineers high-quality, reusable prompts from messy conversations, vague requests, or rough descriptions. It excavates the real intent behind what someone said, then delivers a clean, copy-ready prompt plus short notes on signals used, assumptions, and what to customize—so you can save workflows, build a prompt library, or recreate results in a fresh conversation.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

## Trigger Phrases

```
"Turn this into a prompt"
"How do I ask this again?"
"What prompt should I use for this?"
"Extract the prompt from this conversation"
"Make this a prompt"
"Save this workflow"
"What did I just do?"
"Help me build a reusable prompt or template"
```
