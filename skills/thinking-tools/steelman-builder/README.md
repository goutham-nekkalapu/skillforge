# steelman-builder

Constructs the strongest possible version of an opposing argument or position—not a straw man or a tepid devil's advocate, but the load-bearing case a thoughtful advocate would make. It grounds the steelman in evidence, values, and precedent, addresses obvious objections to the opposing view, then reflects on what the original position must answer and where the real tension lies.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

## Trigger Phrases

```
"Steelman this"
"What's the best argument against my position?"
"Play devil's advocate but seriously"
"Argue the other side"
"What would a smart opponent say?"
"Make the strongest case for X"
"Give me the best counterargument"
"What's the strongest case against this?"
```
