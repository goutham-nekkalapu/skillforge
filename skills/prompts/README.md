# Prompts

Skills for prompt engineering, prompt extraction, and building reusable prompt libraries.

## Skills in This Group

| Skill | Platform | Description |
|-------|----------|-------------|
| [prompt-archeologist](prompt-archeologist/) | claude.ai / Claude Code / Cursor | Reverse-engineers reusable prompts from conversations and rough descriptions |

## Install All Prompt Skills

```bash
npx skillforge install prompts

# Or via install script
./install.sh prompts
```
