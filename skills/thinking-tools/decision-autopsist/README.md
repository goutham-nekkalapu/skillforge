# decision-autopsist

Reconstructs why a decision played out the way it did—success, failure, or mixed—through structured retrospective analysis. It traces the causal chain from choice to outcome, surfaces mental models and missed signals, separates luck from skill, and extracts concrete lessons you can repeat, change, or watch for next time.

## Platform

- **claude.ai**
- **Claude Code**
- **Cursor**
- Adaptable to other agentic frameworks

## Trigger Phrases

```
"Why did this fail?"
"What went wrong?"
"What did we miss?"
"Do a post-mortem on this decision"
"Retrospective on this decision"
"Why did this work?"
"What should we learn from this?"
"What would we do differently?"
```
