Choose template based on course content:
- **Technical/Programming** — Code-heavy template
- **Theoretical/Mathematical** — Formula-focused template
- **Conceptual/Business** — Framework template
- **Hands-on/Tutorial** — Step-by-step template

## Formatting Best Practices

1. **Hierarchy:** Max 3 levels of headers
2. **Code blocks:** Always include language identifier
3. **Tables:** Keep to 4 columns max for readability
4. **Lists:** Use bullets for unordered, numbers for sequences
5. **Emphasis:** Bold for terms, italics for examples
6. **Length:** Aim for 20-30% of original transcript
7. **Whitespace:** Add blank lines between sections
